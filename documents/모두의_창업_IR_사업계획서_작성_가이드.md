### 단계별 요구 서류 수준

| 단계 | 요구 수준 | 준비해야 할 서류/자료 |
|------|----------|-------------------|
| **1단계 (도전신청서)** | 아이디어 수준 | 도전신청서 1장 (문제-해결-차별점) |
| **2단계 (온라인 심사)** | 사업 구체화 수준 | 3~5분 소개 영상 + 보완 자료 |
| **3단계 (지역 오디션)** | IR 초안 수준 | 7~10분 발표 자료 (시장·팀·BM 포함) |
| **4단계 (전국 본선)** | IR 완성 수준 | 10분 피칭 덱 (PoC·재무계획 포함) |
| **5단계 (최종 오디션)** | 투자 IR 수준 | 15분 풀 피칭 + Q&A 대응 |

> **⚠️ 핵심 인사이트**: 1단계는 "아이디어 1장"이지만,
> 실질적으로 3단계 이후부터는 **VC/AC 수준의 IR 피칭 덱**이 사실상 필요합니다.
> 처음부터 IR 수준으로 준비하는 것이 경쟁에서 유리합니다.

### 축별 상세 평가 항목 및 대응 전략

#### 【축 1】 혁신성 — "기존 대비 무엇이 새로운가?"

| 세부 평가 항목 | 평가 질문 | 높은 점수 기준 |
|--------------|----------|-------------|
| 문제 정의의 참신함 | 기존에 간과된 문제를 발견했는가? | 데이터/사례로 문제의 심각성 입증 |
| 해결 방식의 차별성 | 기존 해결 방식과 어떻게 다른가? | 기존 vs 자사 비교표로 명확 구분 |
| 기술적 독창성 | 새로운 기술이나 조합을 활용하는가? | 특허/논문/PoC로 기술 우위 증명 |
| 비즈니스모델 혁신 | 수익 모델이 참신한가? | 기존 시장에 없는 과금/유통 방식 |

**AI Maker Lab 대응 예시:**

```
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│   혁신성 주장 포인트                                           │
│                                                              │
│   ① 문제 재정의                                               │
│      "AI 교육 = 코딩 교육"이라는 프레임을 깨고                    │
│      "AI 교육 = 상용화 프로세스 코칭"으로 재정의                  │
│                                                              │
│   ② 진로 설계 + 제작 교육 통합                                  │

│                                                              │

│      혁신: 제작 → 배포 → 숏츠 광고 → 시장 반응까지                │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

#### 【축 2】 실현 가능성 — "실제로 만들 수 있는가?"

| 세부 평가 항목 | 평가 질문 | 높은 점수 기준 |
|--------------|----------|-------------|

## 2-2. 한 줄 정의 작성법

### 공식: [타겟] + [행동] + [결과] + [차별점]

| 요소 | 질문 | 예시 (AI Maker Lab) |
|------|------|-------------------|
| **타겟** | 누구를 위한 것인가? | AI 시대 청소년 |
| **행동** | 무엇을 하는가? | 진로 설계부터 제품 상용화까지 |
| **결과** | 어떤 결과를 만드는가? | 완주하게 하는 |
| **차별점** | 기존과 다른 점은? | 코칭 교육 플랫폼 |

### 한 줄 정의 예시 비교

```
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│   ❌ 나쁜 한 줄 정의                                          │
│                                                              │
│   "AI 교육 서비스입니다"                                       │
│   → 너무 넓음, 차별점 없음, 타겟 불명확                        │
│                                                              │
│   "학생들을 위한 코딩 교육 플랫폼"                              │
│   → 기존 서비스와 구분 불가                                    │
│                                                              │
│   ❌ 보통 한 줄 정의                                          │
│                                                              │
│   "AI를 활용한 진로 설계 및 메이커 교육 서비스"                  │
│   → 차별점이 약함, "AI 활용"은 누구나 쓰는 표현                 │
│                                                              │
│   ✅ 좋은 한 줄 정의                                           │
│                                                              │
│   "AI 시대 청소년이 진로 설계 → 제품 제작 → 대회 출품 →         │

│                                                              │
│   → 타겟(청소년) + 과정(6단계) + 차별점(완주·코칭) 명확          │
│                                                              │
│   ✅ 가장 좋은 한 줄 정의 (임팩트 우선)                         │
│                                                              │
│   "배우기만 하고 끝나는 AI 교육을 깨고,                          │
│    학생이 직접 만든 서비스를 세상에 내놓을 때까지                  │
│    끝까지 코칭하는 상용화 교육 플랫폼"                           │
│                                                              │
│   → 문제(배우기만) + 솔루션(세상에 내놓을 때까지) + 핵심(코칭)    │

## 2-3. 아이디어 설명 작성 전략

### 문제 → 해결 → 차별점 3단 구조

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【1. 문제】 ← 공감을 끌어내는 팩트

  "현재 한국의 AI 교육은 '체험'에서 끝납니다."
  
  • AI 교육 의무화(2025~)로 수업은 늘었지만,
    배운 뒤 대회·상용화로 이어지는 교육은 전무
  • 진로 컨설팅은 회당 30~100만 원 — 정보 격차 심화
  • 모두의 창업 6.2만 명 지원 = 학생도 "만들어서 내놓고 싶다"
    13세가 IoT 안전 시스템으로 선발 → 제작을 도울 곳이 없음

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【2. 해결】 ← 구체적 메커니즘

  "AI Maker Lab = 상용화 프로세스를 끝까지 코칭하는 교육"

  • 2개 플랫폼: aicareerpath.co.kr (진로 설계·무료)
                aimakerlab.com (제작 교육·프리미엄)
  • 2단계 교육: BASIC (주입식·프로세스 학습)
               → ADVANCED (자기주도·상용화 프로젝트)
  • 6단계 코칭: 문제 발굴 → 기획 → 제작 → 출시 → 홍보 → 반응

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【3. 차별점】 ← 왜 당신이어야 하는가

  "직접 만들어봤고, 직접 가르쳐봤고, 직접 팔아봤습니다"

  • 링고팡: 실제 오픈·운영 중인 상용 제품 → 커리큘럼의 원본
  • 가천대 5년: 대학 정규 수업 반복 검증 → 교육 자산
  • 3개 서비스 동시 운영: AI 오케스트라로 1인 3서비스
  • 숏폼 마케팅: 힉스필드·캡컷·프리픽 → 만든 것을 팔 수 있음

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 멘토가 보는 5가지

```
┌─────────────────────────────────────────────────────────────┐
│                                                              │
│   ① 진정성 — "왜 이 문제를 풀려 하는가?"                       │
│                                                              │
│      → 10년간 직접 만들고, 가르쳐온 경험에서 자연스럽게 출발     │
│      → "AI 교육 시장이 크니까"가 아니라                        │
│        "내가 겪어보니 이게 문제더라"                            │
│                                                              │
│   ② 실행력 — "말만 하는가, 이미 움직이고 있는가?"               │
│                                                              │
│      → 3개 서비스 이미 가동 중                                 │
│      → 30종 커리큘럼 이미 설계 완료                            │
│      → "~할 예정"이 아니라 "이미 했고 다음 단계가 필요"         │
│                                                              │
│   ③ 학습 속도 — "피드백을 받으면 빠르게 개선하는가?"             │
│                                                              │
│      → 가천대 5년 = 학생 피드백 기반 커리큘럼 반복 개선          │
│      → AI 오케스트라 = 빠른 개발·배포·수정 사이클               │
│                                                              │
│   ④ 시장 감각 — "고객이 누구인지 아는가?"                      │
│                                                              │
│      → 5개 세그먼트 명확 (B2C 온/오프, B2C 학부모, B2G, B2B)   │
│      → 단가·전환율 계산 가능                                   │
│                                                              │
│   ⑤ 끈기 — "안 되면 어떻게 할 것인가?"                        │
│                                                              │
│      → 10년 경력 자체가 끈기 증명                              │
│      → 외주 개발로 즉시 수익 창출 가능 = 생존력                 │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

│   "AI 교육의 95%가 체험에서 끝나 상용화 경험이 0건" ← 이게 문제  │
│                                                              │
│   ❌ 실수 2: 솔루션에 기능만 나열                              │
│   "RIASEC 검사, 200개 직업 DB, AI 협업..." ← 기능 목록          │
│   "진로를 설계하고 → 제품을 만들고 → 시장에 내놓는             │
│    하나의 사이클을 완주" ← 가치 제안                            │
│                                                              │
│   ❌ 실수 3: 숫자 없는 시장 분석                               │
│   "AI 교육 시장이 성장하고 있습니다" ← 누구나 쓸 수 있음         │
│   "TAM 6조, CAGR 15%, 의무화 정책으로 2030년 10조 전망"         │
│   ← 구체적 수치 + 출처                                        │
│                                                              │
│   ❌ 실수 4: "~할 예정입니다"만 반복                            │
│   예비창업자도 이미 한 것이 있어야 함                            │
│   사이트 구축, 고객 인터뷰, 프로토타입, 커리큘럼 설계 등          │
│                                                              │
│   ❌ 실수 5: 경쟁사를 무시하거나 회피                           │
│   "경쟁사가 없습니다" ← 시장이 없다는 뜻으로 해석됨              │
│   "경쟁사는 있지만 이 부분을 안 합니다" ← 차별점 명확            │
│                                                              │
│   ❌ 실수 6: 팀 슬라이드에서 학력만 나열                        │
│   "XX대학교 YY학과 졸업" ← 실행력 증명 안 됨                    │
│   "10년간 50개 프로젝트 직접 제작, 5년 대학 강의" ← 실적 중심     │
│                                                              │
│   ❌ 실수 7: 재무계획에 근거 없음                               │
│   "2027년 매출 2.1억 예상" ← 어떻게?                           │
│   "10개교×3회×50만=1,500만" ← 계산식 공개                      │
│                                                              │
│   ❌ 실수 8: 4축 중 하나를 빠뜨림                              │
│   혁신적이지만 실현 가능성 언급 없음 → 0점 → 탈락               │
│   반드시 4축 체크리스트로 자가 검증                              │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```
