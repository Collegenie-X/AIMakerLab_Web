## 📖 과정 소개

### 타이틀
"왜 게임 제작 프로젝트인가?"

### 내용

**중학생이 가장 흥미있어 하는 주제: 게임**

게임은 중학생들이 가장 친숙하고 흥미를 느끼는 콘텐츠입니다. 이 과정에서는 복잡한 프로그래밍 없이도 **AI를 동반자로 활용**하여 실제로 플레이 가능한 게임을 만듭니다.

**3가지 역할 체험: 기획자 → 실행자 → 디버거**

실제 게임 개발 과정처럼 3가지 역할을 순환하며 경험합니다:

1. **기획자 (Planner)**: 게임 아이디어 구상, 스토리 설계, 게임 규칙 정의
2. **실행자 (Developer)**: AI와 협업하여 게임 콘텐츠 제작, 선택지 구현
3. **디버거 (Debugger)**: 게임 테스트, 문제점 발견, 개선 방안 도출

**AI를 동반자로 활용하는 방법**

ChatGPT는 단순한 도구가 아니라 **함께 일하는 팀원**입니다:

- **브레인스토밍 파트너**: "이런 게임 어때?" → AI가 아이디어 확장
- **콘텐츠 제작 조수**: "이 장면 대사 만들어줘" → AI가 초안 작성
- **테스트 플레이어**: "이 선택지 재미있어?" → AI가 피드백 제공
- **개선 컨설턴트**: "어떻게 더 재미있게 만들까?" → AI가 제안

**벤치마킹 → 페르소나 → 실행 → 완성**

1. **벤치마킹**: 인기 게임 분석 (어떤 요소가 재미있는가?)
2. **페르소나 설정**: 우리 게임의 타겟 플레이어는 누구인가?
3. **실행**: AI와 협업하여 단계별로 제작
4. **완성**: 테스트하고 개선하여 최종 결과물 발표

**프로젝트 기반 학습의 힘**

- ✅ 실제 결과물이 나옴 (성취감)
- ✅ 친구들과 공유 가능 (자랑할 수 있음)
- ✅ 창의성 발휘 (내 아이디어 구현)
- ✅ 문제 해결 능력 향상 (디버깅 과정)
- ✅ 협업 능력 개발 (AI와 소통)

### 이미지 (3개)
- 기획자-실행자-디버거 역할 순환 다이어그램
- AI와 협업하는 게임 제작 과정 인포그래픽

## 1차시: 게임 벤치마킹 & 아이디어 기획 (기획자 역할)

### 🎯 차시 목표
- 인기 게임의 재미 요소 분석
- 타겟 플레이어 페르소나 설정
- 나만의 게임 아이디어 구체화

### 📖 수업 흐름 (45분)

#### 도입 (10분)
**활동: 좋아하는 게임 이야기하기**

```
💬 질문:
- 요즘 가장 재미있게 하는 게임은?
- 그 게임의 어떤 점이 재미있나요?
- 친구들에게 추천하고 싶은 이유는?
```

**강사 설명:**
- 오늘부터 6차시 동안 여러분이 직접 게임을 만듭니다
- AI를 팀원처럼 활용하여 실제 플레이 가능한 게임 완성
- 첫 시간에는 '기획자' 역할을 경험합니다

#### 전개 1: 게임 벤치마킹 (15분)
**활동: 인기 게임 분석하기**

**교사 시연:**
```
ChatGPT에게 질문:
"중학생들이 좋아하는 인터랙티브 게임의 특징을 분석해줘.
다음 항목으로 정리해줘:
1. 스토리 구조
2. 선택지 시스템
3. 캐릭터 설정
4. 재미 요소
5. 성공 요인"
```

**학생 활동:**
1. ChatGPT 응답 읽고 이해하기
2. 자신이 좋아하는 게임에 적용해보기
3. 워크시트에 분석 결과 정리

**워크시트: 게임 분석표**
```
게임 이름: _______________

✅ 스토리: 어떤 이야기인가?
✅ 선택지: 어떤 선택을 할 수 있나?
✅ 캐릭터: 주인공은 누구인가?
✅ 재미 요소: 왜 재미있나?
✅ 배울 점: 내 게임에 적용할 점은?
```

#### 전개 2: 페르소나 설정 (10분)
**활동: 타겟 플레이어 정의하기**

**ChatGPT 활용:**
```
"내가 만들 게임의 타겟 플레이어 페르소나를 만들어줘.
중학생 대상이고, 다음 정보를 포함해줘:
- 이름과 나이
- 좋아하는 게임 장르
- 게임 플레이 스타일
- 기대하는 재미 요소
- 플레이 가능 시간"
```

**학생 활동:**
1. AI가 제안한 페르소나 검토
2. 자신의 친구를 떠올리며 수정
3. 최종 페르소나 확정

**페르소나 예시:**
```
이름: 민준 (중2, 14세)
좋아하는 장르: 판타지, RPG, 추리
플레이 스타일: 신중하게 선택, 모든 엔딩 보고 싶어함
기대 요소: 반전 있는 스토리, 의미 있는 선택
플레이 시간: 20-30분 정도
```

#### 전개 3: 게임 아이디어 기획 (10분)
**활동: 나만의 게임 콘셉트 정하기**

**ChatGPT 브레인스토밍:**
```
"중학생이 재미있어할 인터랙티브 게임 아이디어 10가지를 제안해줘.
각 아이디어마다:
- 장르 (판타지/SF/학교/미스터리 등)
- 핵심 스토리 (한 줄)
- 주요 선택지 3가지
- 예상 플레이 시간
을 포함해줘"
```

**학생 활동:**
1. 10가지 아이디어 중 마음에 드는 것 3개 선택
2. 각 아이디어의 장단점 비교
3. 최종 1개 선택하고 이유 작성

**선택 기준:**
- ✅ 내가 만들고 싶은가?
- ✅ 친구들이 재미있어할까?
- ✅ 6차시 안에 완성 가능한가?
- ✅ 나만의 특별한 점이 있는가?

#### 정리 (10분)
**활동: 1차시 결과물 정리**

**학생 발표:**
- 선택한 게임 아이디어 소개 (1인당 1분)
- 왜 이 아이디어를 선택했는지 설명
- 어떤 점이 재미있을 것 같은지 공유

**교사 피드백:**
- 각 아이디어의 강점 칭찬
- 개선 방향 제안
- 다음 차시 예고

### 📝 결과물
- [ ] 게임 분석표 작성 완료
- [ ] 타겟 플레이어 페르소나 설정
- [ ] 게임 아이디어 1개 확정
- [ ] 선택 이유 및 기대 효과 작성

### 🏠 과제
```
ChatGPT에게 질문하기:
"내 게임 아이디어: [자신의 아이디어]
이 게임을 더 재미있게 만들 수 있는 요소 5가지를 제안해줘"

AI의 제안을 읽고, 마음에 드는 것 3가지 선택해오기
```

## 2차시: 게임 스토리 & 캐릭터 설계 (기획자 역할)

### 🎯 차시 목표
- 게임의 전체 스토리 구조 설계
- 매력적인 캐릭터 설정
- 주요 선택지 포인트 정의

### 📖 수업 흐름 (45분)

#### 도입 (5분)
**활동: 과제 공유**

- 각자 AI에게 받은 제안 중 선택한 3가지 공유
- 같은 아이디어를 선택한 친구끼리 비교
- 새로운 아이디어 얻기

#### 전개 1: 스토리 구조 설계 (15분)
**활동: 3막 구조로 스토리 짜기**

**교사 설명:**
```
게임 스토리는 3막 구조로 만듭니다:
- 1막 (시작): 주인공 소개, 문제 발생
- 2막 (전개): 선택과 도전, 갈등 심화
- 3막 (결말): 선택의 결과, 엔딩 (3가지)
```

**ChatGPT 활용:**
```
"다음 게임 아이디어를 3막 구조로 상세하게 기획해줘:
[자신의 게임 아이디어]

각 막마다:
- 주요 사건 3가지
- 플레이어 선택 포인트 2개
- 각 선택의 결과
- 다음 막으로 연결되는 방법
을 포함해줘"
```

**학생 활동:**
1. AI가 제안한 스토리 구조 읽기
2. 마음에 안 드는 부분 수정 요청
3. 자신만의 아이디어 추가
4. 최종 스토리 구조 확정

**스토리 구조 템플릿:**
```
=== 1막: 시작 ===
장면 1: [주인공 일상]
장면 2: [문제 발생]
장면 3: [모험 시작]
→ 선택 포인트 1: [A 또는 B]

=== 2막: 전개 ===
장면 4: [도전 1]
→ 선택 포인트 2: [C 또는 D]
장면 5: [도전 2]
→ 선택 포인트 3: [E 또는 F]
장면 6: [갈등 최고조]

=== 3막: 결말 ===
엔딩 A: [선택의 결과 1]
엔딩 B: [선택의 결과 2]
엔딩 C: [선택의 결과 3]
```

#### 전개 2: 캐릭터 설정 (15분)
**활동: 주인공과 주요 인물 만들기**

**ChatGPT 활용:**
```
"내 게임의 주인공 캐릭터를 상세하게 만들어줘:
게임 배경: [자신의 게임 배경]
주인공 역할: [예: 마법학교 신입생]

다음 정보를 포함해줘:
- 이름, 나이, 외모
- 성격 (장점 3개, 단점 2개)
- 배경 스토리
- 특별한 능력이나 특징
- 목표와 동기
- 말투 예시 3가지"
```

**학생 활동:**
1. 주인공 캐릭터 검토 및 수정
2. 조연 캐릭터 2-3명 추가 요청
3. 캐릭터 간 관계 설정
4. 캐릭터 프로필 카드 작성

**캐릭터 프로필 카드:**
```
┌─────────────────────────┐
│  이름: 김서연           │
│  나이: 14세             │
│  역할: 시간여행 학생    │
├─────────────────────────┤
│ 성격:                   │
│ ✅ 호기심 많음          │
│ ✅ 용감함               │
│ ✅ 친구 중시            │
│ ⚠️ 충동적              │
│ ⚠️ 계획성 부족         │
├─────────────────────────┤
│ 특별한 능력:            │
│ 과거로 10분 되돌리기    │
│ (하루 3번만 가능)       │
├─────────────────────────┤
│ 목표:                   │
│ 미래를 바꿀 사건 찾기   │
└─────────────────────────┘
```

#### 전개 3: 선택지 포인트 정의 (10분)
**활동: 의미 있는 선택 만들기**

**교사 설명:**
```
좋은 선택지의 조건:
1. 정답이 없어야 함 (둘 다 장단점)
2. 결과가 달라야 함 (의미 있는 선택)
3. 캐릭터 성격과 연결
4. 플레이어가 고민하게 만들기
```

**ChatGPT 활용:**
```
"내 게임의 주요 선택지 5개를 만들어줘.
각 선택지마다:
- 상황 설명
- 선택지 A (장점/단점)
- 선택지 B (장점/단점)
- 각 선택의 결과
- 다음 스토리 연결
을 포함해줘"
```

**학생 활동:**
1. AI가 제안한 선택지 검토
2. 너무 쉬운 선택 → 더 어렵게 수정
3. 정답이 있는 선택 → 양쪽 다 매력적으로 수정
4. 최종 선택지 5개 확정

**선택지 예시:**
```
상황: 친구가 시험 답안을 보여달라고 함

선택 A: 보여준다
✅ 장점: 친구 관계 유지, 친구가 좋은 점수
⚠️ 단점: 양심의 가책, 나중에 문제 발생 가능

선택 B: 거절한다
✅ 장점: 정직함, 친구가 스스로 공부
⚠️ 단점: 친구 관계 악화, 당장 미안함

→ 어느 쪽을 선택하든 의미 있는 결과
```

#### 정리 (10분)
**활동: 2차시 결과물 점검**

**체크리스트:**
- [ ] 3막 구조 스토리 완성
- [ ] 주인공 캐릭터 프로필 작성
- [ ] 조연 캐릭터 2-3명 설정
- [ ] 주요 선택지 5개 확정
- [ ] 각 선택의 결과 정의

**교사 피드백:**

오늘은 '디버거(Debugger)' 역할입니다!

- ✅ 품질 보증: 플레이어 관점에서 평가
- 🔄 반복 개선: 완벽할 때까지

- 길이: 300자
- 플레이어에게 주는 메시지 포함"

**엔딩 B: 새드 엔딩 (5분)**

**학생 프롬프트:**
```

- 이전 선택: [새드 엔딩으로 이어지는 선택들]
- 갈등 미해결 또는 희생

- 슬프지만 의미 있는 마무리

**엔딩 C: 반전 엔딩 (5분)**

- 예상 밖의 전개

- 길이: 350자

#### 전개 2: 전체 게임 테스트 (15분)
**활동: 모든 경로 플레이해보기**

**테스트 체크리스트:**

**1. 스토리 흐름 테스트**
```
✅ 시작부터 끝까지 자연스러운가?

**2. 선택지 테스트**

✅ 모든 선택지가 작동하는가?
✅ 선택의 결과가 다른가?
✅ 선택이 의미 있는가?
✅ 선택지 설명이 명확한가?

✅ 캐릭터 성격이 일관적인가?

✅ 행동이 성격과 맞는가?
✅ 성장이 자연스러운가?

**5. 재미 요소 테스트**
```
✅ 흥미로운가?
✅ 다음이 궁금한가?
✅ 다시 플레이하고 싶은가?

**학생 활동:**
1. 자신의 게임을 처음부터 끝까지 플레이

3. 문제점 발견 시 워크시트에 기록
4. 우선순위 정하기 (심각도 순)

**버그 리포트 워크시트:**
```
┌─────────────────────────────┐

## 💡 FAQ

**Q1: 코딩을 전혀 모르는데 게임을 만들 수 있나요?**
```
A: 네! 이 과정은 코딩 없이 텍스트 기반 게임을 만듭니다.
AI가 콘텐츠 제작을 도와주므로 아이디어와 창의성만 있으면 됩니다.
```

**Q2: ChatGPT 유료 버전이 필요한가요?**
```
A: 무료 버전으로도 충분합니다.
다만 유료 버전(GPT-4)을 사용하면 더 높은 품질의 결과를 얻을 수 있습니다.
```

**Q3: 6차시에 정말 게임을 완성할 수 있나요?**
```
A: 네! 텍스트 기반 게임은 6차시 내 완성 가능합니다.
단, 범위를 적절히 조절하는 것이 중요합니다.
(스토리 10-15개 장면, 선택지 5-7개, 엔딩 2-3개 권장)
```

**Q4: 게임을 친구들과 공유할 수 있나요?**
```
A: 네! 구글 문서로 공유하거나,
Twine 등의 툴로 변환하면 웹 게임으로 만들 수 있습니다.
```

**Q5: AI가 만든 게임도 내 작품인가요?**
```
A: 네! AI는 도구일 뿐, 아이디어와 기획, 최종 결정은
모두 학생이 하므로 학생의 작품입니다.
```

**Q6: 게임 주제에 제한이 있나요?**
```
A: 폭력적, 선정적, 차별적 내용만 피하면
자유롭게 선택할 수 있습니다.
교육적 가치보다 학생의 흥미를 우선합니다.
```

**Q7: 프로그래밍을 배우고 싶은데 이 과정이 도움이 되나요?**
```
A: 네! 게임 제작의 기획-실행-디버깅 과정은
실제 프로그래밍과 동일한 사고 과정입니다.
이후 코딩을 배울 때 큰 도움이 됩니다.
```

**Q8: 한 차시에 완성하지 못하면 어떻게 하나요?**
```
A: 집에서 계속 작업할 수 있습니다.
다음 차시 초반에 추가 시간을 제공하거나,
범위를 조절하여 완성도를 높입니다.
```

## 🎊 마무리

이 6차시 커리큘럼은 중학생들이 **AI를 동반자로 활용**하여 실제 결과물을 만드는 경험을 제공합니다.

### 핵심 가치

**1. 실제 결과물**
- 친구들과 공유 가능한 게임
- 성취감과 자부심
- 포트폴리오로 활용

**2. 역할 체험**
- 기획자: 아이디어와 설계
- 실행자: 콘텐츠 제작
- 디버거: 품질 관리
- 크리에이터: 통합 역량

**3. AI 활용 능력**
- AI를 도구가 아닌 파트너로
- 효과적인 프롬프트 작성
- 결과 평가 및 개선
- 윤리적 사용

**4. 21세기 역량**
- 창의성
- 문제 해결
- 협업 (AI와의)
- 디지털 리터러시

### 기대 효과

```
학생들은 이 과정을 통해:
✅ "나도 게임을 만들 수 있다"는 자신감

✅ 기획부터 완성까지의 전 과정 이해
✅ 창의적 문제 해결 능력 향상
✅ 디지털 시대의 크리에이터 마인드셋
```
