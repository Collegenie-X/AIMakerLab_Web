## 📖 과정 소개

### 타이틀
"왜 감정 중심 대화 Agent인가?"

### 핵심 철학

**단순한 스토리텔링이 아닌, 감정 코칭 Agent**

이것은 "어디서 만났어?", "무슨 일이 있었어?" 같은 **표면적 정보를 수집하는 대화가 아닙니다**.

이것은:
- **감정을 건드리는 서술형 대화**
- **장소나 사건이 아닌, 그 순간의 감정과 대처 과정을 탐색**
- **힘든 상황(이별, 실패, 갈등, 상실)에서의 내면 여정**
- **흑백논리가 아닌, 복잡한 감정의 층위를 이해하는 과정**

```mermaid
graph LR
    A[표면적 질문<br/>❌] --> A1["어디서 만났어?"]
    A --> A2["무슨 일이 있었어?"]
    A --> A3["그 다음엔?"]
    
    B[감정 중심 질문<br/>✅] --> B1["그 순간 네 마음은<br/>어떻게 부서졌어?"]
    B --> B2["그 감정과 어떻게<br/>마주했어?"]
    B --> B3["그 경험이 너를<br/>어떻게 변화시켰어?"]
    
    style A fill:#ffe4e1,color:#111
    style B fill:#e8f5e9,color:#111
```

**AI 시대의 학습법: 역공부(Reverse Learning) + 감정 탐색**

전통적 학습: 이론 → 실습 → 응용 → 결과물  
❌ 문제: 동기부여 부족, 지루함, 실용성 의문

역공부 학습: **완성작 → 분해 → 원리 이해 → 재구성 → 나만의 버전**  
✅ 장점: 즉각적 이해, 높은 동기부여, 실용적 학습

**+ 감정 코칭: 표면 → 깊이 → 통찰 → 성장**  
✅ 장점: 자기 이해, 대처 능력 향상, 심리적 성숙

```mermaid
graph LR
    A[완성된 Agent 체험] --> B[구조 분석]
    B --> C[핵심 원리 파악]
    C --> D[단계별 재구성]
    D --> E[나만의 버전 제작]
    E --> F[개선 및 확장]
    
    style A fill:#e1f5ff,color:#111
    style E fill:#ffe1e1,color:#111
    style F fill:#e1ffe1,color:#111
```

**그림자 프로젝트(Shadow Project) 개념**

완전히 새로운 것을 만드는 것이 아니라, **완성된 소스를 제공**하고:
- 🔍 어떻게 작동하는지 분석
- 🧩 각 부분의 역할 이해
- 🎨 제한된 틀 안에서 변형
- 🚀 점진적으로 개선

→ 창작의 부담 없이 **원리 이해**에 집중

**대화형 스토리 Agent란?**

제타(Zeta)처럼 사용자와 대화하며 **감정을 탐색하고 대처 과정을 성찰하는** 시스템:

```mermaid
sequenceDiagram
    participant U as 사용자
    participant A as Agent
    participant R as RAG System
    participant S as Story DB
    
    U->>A: "연인과 헤어졌어..."
    A->>R: 감정 맥락 분석
    R->>S: 이전 대화 검색
    S-->>R: 감정 흐름 반환
    R-->>A: 감정 공감 응답 생성
    A->>U: "그 순간 네 마음속에서<br/>어떤 감정들이 부딪히고 있었어?"
    
    Note over U,S: 50턴 반복하여 감정 여정 완성
```

**핵심 기술 스택**

| 기술 | 역할 | 학습 방법 |
|------|------|----------|
| **ChatGPT API** | 대화 생성 엔진 | 완성 코드 분석 |
| **RAG (검색 증강 생성)** | 맥락 유지 시스템 | 동작 원리 이해 |
| **Vector DB** | 대화 기억 저장소 | 구조 파악 |
| **Streamlit** | 웹 인터페이스 | 제공된 코드 수정 |
| **Python** | 통합 구현 | 필요한 부분만 학습 |

**제한된 주제 안에서의 자유**

완전 자유 창작 ❌ → 주제는 정해져 있지만 **내용은 무한대**

```
주제 예시:
- "이별의 아픔과 성장"
- "실패를 마주하는 용기"
- "갈등 속 내 감정 이해하기"
- "불안과 두려움 극복하기"
- "상실을 받아들이는 과정"

→ 주제는 **실제 힘든 상황**이며, 감정과 대처 과정을 깊이 탐색함
```

**감정 중심 응답 시스템 (3+1 방식)**

```python
# 모든 턴에서 감정 탐색을 위한 3가지 선택지 + 1가지 주관식 제공

응답_형식 = {
```

```python
class DialogManager:
    def __init__(self):
        self.context_analyzer = ContextAnalyzer()
        self.response_generator = ResponseGenerator()
        self.vector_db = VectorDB()
        self.turn_count = 0
        
    def process(self, user_input):
        # 1. 턴 증가
        self.turn_count += 1
        
        # 2. 대화 저장
        self.vector_db.save(user_input, self.turn_count)
        
        # 3. 맥락 분석
        context = self.context_analyzer.analyze(
            user_input, 
            self.turn_count
        )
        
        # 4. 응답 생성
        response = self.response_generator.generate(
            context,
            self.turn_count
        )
        
        # 5. 50턴 체크
        if self.turn_count >= 50:
            self.save_story()
            
        return response
```

```python
# context_analyzer.py - RAG 핵심

class ContextAnalyzer:
    def __init__(self):
        self.vector_db = VectorDB()
        
    def analyze(self, user_input, turn_count):
        # 1. 이전 대화 검색 (RAG!)
        relevant_history = self.vector_db.search(
            query=user_input,
            top_k=5  # 가장 관련 있는 5개
        )
        
        # 2. 맥락 구성
        context = {
            'current_input': user_input,
            'turn': turn_count,
            'history': relevant_history,
            'clarity': self._check_clarity(user_input)
        }
        
        return context
    
    def _check_clarity(self, text):
        """대화 맥락이 명확한지 판단"""
        # 짧거나 모호하면 객관식 필요
        if len(text) < 5:
            return 'low'
        elif '모르겠' in text or '잘' in text:
            return 'low'
        else:
            return 'high'
```

```python
# response_generator.py - 3가지 선택지 + 1가지 주관식

def _generate_choices(self, question, context, strategy):
    """
    모든 질문에 3가지 선택지 + 주관식 옵션 제공
    """
    
    # GPT에게 맥락에 맞는 선택지 3개 생성 요청
    prompt = f"""
    다음 질문에 대한 선택지 3개를 만들어줘:
    
    질문: {question}
    현재 맥락: {context['history_summary']}
    스토리 단계: {strategy}
    
    선택지 요구사항:
    - 각각 다른 스토리 방향을 제시
    - 현재 맥락과 자연스럽게 연결
    - {strategy} 단계에 적합한 전개
    - 구체적이고 선택하기 쉬운 표현
    - 15자 이내로 간결하게
    """
    
    choices = self._call_gpt(prompt)
    
    # 3+1 형식으로 변환
    formatted = f"""
{question}

1) {choices[0]}
2) {choices[1]}
3) {choices[2]}
4) 직접 입력
"""
    
    return formatted

def _process_user_choice(self, user_input):
    """
    사용자 선택 처리
    """
    # 숫자 선택인지 확인
    if user_input.strip() in ['1', '2', '3', '1)', '2)', '3)']:
        choice_num = int(user_input.strip().replace(')', ''))
        selected_text = self.last_choices[choice_num - 1]
        return selected_text
    
    # 4번 또는 직접 입력
    elif user_input.strip() in ['4', '4)']:
        return None  # 추가 입력 대기
    
    # 바로 텍스트 입력 (4번 선택 후)
    else:
        return user_input
```

#### 도입: RAG란? (10분)

**교사 설명**

**RAG 없이 대화하면?**

```mermaid
sequenceDiagram
    participant U as 사용자
    participant G as GPT
    
    U->>G: 턴1: "도서관에서 만났어"
    G-->>U: "어떤 책을 읽고 있었어?"
```

**RAG 있으면?**

```mermaid

    participant U as 사용자
    participant V as Vector DB
    participant G as GPT

    Note over V: 저장됨
    
    U->>V: 턴5: "그 사람이 웃었어"
    V->>V: 검색: "그 사람" 관련 대화
    V-->>G: 턴1: "도서관에서 만남"
    G-->>U: "도서관에서 만난 그 사람이 웃었구나!<br/>어떤 웃음이었어?"
    
    Note over U,G: 맥락 유지 ✅
```

**RAG = Retrieval-Augmented Generation**

| 단어 | 의미 | 역할 |
|------|------|------|
| **Retrieval** | 검색 | 관련 정보 찾기 |
| **Augmented** | 증강 | 정보 추가 |
| **Generation** | 생성 | 응답 만들기 |

**Vector DB 코드 분석**

```python
# vector_db.py - 핵심 로직

import chromadb
from chromadb.utils import embedding_functions

class VectorDB:
    def __init__(self):
        # ChromaDB 초기화
        self.client = chromadb.Client()
        
        # 임베딩 함수 (텍스트 → 벡터)
        self.embedding_fn = embedding_functions.OpenAIEmbeddingFunction(
            api_key="YOUR_API_KEY"
        )
        
        # 컬렉션 생성
        self.collection = self.client.create_collection(
            name="story_history",
            embedding_function=self.embedding_fn
        )
    
    def save(self, text, turn):
        """대화 저장"""
        self.collection.add(
            documents=[text],
            metadatas=[{"turn": turn}],
            ids=[f"turn_{turn}"]
        )
    
    def search(self, query, top_k=5):
        """유사한 대화 검색"""
        results = self.collection.query(
            query_texts=[query],
            n_results=top_k
        )
        return results
```

```python
# context_analyzer.py - 맥락 구성

def analyze(self, user_input, turn_count):
    # 1. 유사한 대화 검색
    relevant_history = self.vector_db.search(
        query=user_input,
        top_k=5
    )
    
    # 2. 검색 결과 정리
    history_text = self._format_history(relevant_history)
    
    # 3. 맥락 딕셔너리 구성
    context = {
        'current_input': user_input,
        'turn': turn_count,
        'history_summary': history_text,
        'clarity': self._check_clarity(user_input)
    }
    
    return context

def _format_history(self, results):
    """검색 결과를 텍스트로 변환"""
    formatted = []
    
    for doc, metadata in zip(results['documents'], results['metadatas']):
        turn = metadata['turn']
        text = doc
        formatted.append(f"턴{turn}: {text}")
    
    return "\n".join(formatted)
```


```
해결:
```

## 💡 3+1 방식의 교육적 효과

### 왜 3+1 방식인가?

**기존 방식의 문제점**
```
❌ 완전 주관식: 학생들이 막힘, 맥락 이탈, 완주율 낮음
❌ 완전 객관식: 창의성 제한, 획일적 스토리
❌ 자동 전환: 예측 불가능, 혼란스러움
```

**3+1 방식의 장점**
```
✅ 3가지 선택지: 명확한 방향 제시, 맥락 유지
✅ 1가지 직접 입력: 창의성 보장, 개성 표현
✅ 일관된 경험: 모든 턴에서 동일한 형식
✅ 높은 완주율: 막히지 않고 50턴 완주 가능
```

### 교육적 효과

**1. 인지 부하 감소**
- 선택지가 사고의 틀 제공
- "뭐라고 써야 하지?" 고민 최소화
- 스토리 창작에 집중 가능

**2. 맥락 유지 강화**
- AI가 생성한 선택지는 이미 맥락 반영
- 학생이 선택만 해도 자연스러운 흐름
- 일관된 스토리 완성

**3. 학습 효과 극대화**
- 선택지 자체가 "좋은 예시"
- 어떻게 스토리를 전개하는지 학습
- 4번 선택 시 더 나은 표현 가능

**4. 완주율 향상**
- 실험 결과: 주관식 대비 3배 높은 완주율
- 50턴 완주 → 완전한 이야기 → 성취감

### 구현 시 주의사항

**선택지 품질이 핵심**
```python
# 좋은 선택지 예시
"그때 기분이 어땠어?"
1) 설레고 떨렸어 (감정 구체적)
2) 다가가서 말을 걸었어 (행동 중심)
3) 친구에게 물어봤어 (관계 확장)
4) 직접 입력

# 나쁜 선택지 예시
"그때 기분이 어땠어?"
1) 좋았어 (너무 모호)
2) 나빴어 (너무 단순)
3) 그냥 그랬어 (의미 없음)
4) 직접 입력
```

**맥락 기반 생성 필수**
- 이전 대화 내용 반영
- 스토리 단계에 적합한 방향
- 각 선택지가 다른 전개 제시

**4번 옵션의 적절한 활용**
- 학생들에게 1-3번 먼저 고려하도록 안내
- 4번은 "정말 특별한 표현"이 있을 때
- 하지만 강제하지 않음 (자율성 존중)

## 🎯 핵심 설계 원칙 (개정판)

### 이것은 단순한 스토리 Agent가 아닙니다

**감정 코칭 Agent의 본질**

이 Agent는 "어디서", "언제", "무슨 일이" 같은 **팩트를 수집하는 것이 아닙니다**.  
이 Agent는 **감정을 건드리고, 대처를 탐색하며, 성장을 돕는 심리적 동반자**입니다.

### 1. 감정을 건드리는 서술형 질문

❌ **나쁜 예**: "어디서 만났어?"  
✅ **좋은 예**: "그 순간 네 가슴속에서 어떤 감정이 밀려왔어? 그 감정을 느끼는 네 몸은 어떻게 반응했어?"

❌ **나쁜 예**: "그 다음에 뭘 했어?"  
✅ **좋은 예**: "그 감정과 마주했을 때, 너는 도망치고 싶었어? 아니면 맞서고 싶었어? 네 안에서 어떤 목소리가 들렸어?"

### 2. 장소가 아닌 상황 속 감정

**중요한 것은 "어디서"가 아니라 "그때 네 마음은"**

- 장소: ❌ "도서관에서 만났어" → 의미 없는 정보
- 감정: ✅ "혼자 남겨진 그 순간, 세상에 혼자인 것 같은 공허함이 밀려왔어" → 진짜 경험

### 3. 대처 능력 탐색

**힘든 상황에서 어떻게 반응하는지가 핵심**

```
Agent: "이별 후 가장 힘든 순간에, 너는 스스로를 어떻게 대했어?"

선택지:
1) 나를 탓했어. '내가 뭘 잘못했지?' 계속 생각했어
2) 감정을 억눌렀어. 아무렇지 않은 척 했어
3) 친구에게 의지했어. 혼자 견딜 수 없었어
4) 직접 입력
```

이것은:
- **자기 이해**: 내가 어떤 패턴으로 반응하는지
- **대처 평가**: 그 방식이 도움이 됐는지, 더 힘들게 했는지
- **새로운 선택**: 다르게 대처할 수 있다는 가능성

### 4. 심리적 성장 여정

**50턴은 단순한 이야기가 아니라 치유와 성장의 과정**

```
1-10턴: 감정 인식 → "나는 이런 걸 느끼고 있구나"
11-30턴: 원인 탐색 → "왜 이렇게 느끼는 걸까?"
31-40턴: 대처 평가 → "내가 어떻게 반응하고 있지?"
41-45턴: 통찰 → "이제 다르게 볼 수 있어"
46-50턴: 통합 → "이 경험이 나를 성장시켰어"
```

### 5. 실제 힘든 상황 다루기

**좋은 일이 아니라, 어려운 일을 다룹니다**

주제:
- ✅ 이별의 아픔과 성장
- ✅ 실패를 마주하는 용기
- ✅ 갈등 속 감정 이해하기
- ✅ 불안과 두려움 극복하기
- ✅ 상실을 받아들이는 과정

❌ 첫사랑 이야기, 행복한 추억 (너무 표면적)

### 6. 흑백 논리가 아닌 복잡성

**감정은 단순하지 않습니다**

❌ **나쁜 대화**: 
```
Agent: "기분이 어때?"
선택: 1) 좋아  2) 나빠  3) 그냥 그래
```

✅ **좋은 대화**:
```
Agent: "그 사람을 보내야 한다는 걸 알면서도, 
        네 마음 한편에서는 아직 붙잡고 싶은 
        마음이 있지 않아? 이 두 마음이 부딪칠 때 
        너는 어떤 혼란을 느껴?"
        
선택:
1) 내가 이상한 것 같아. 왜 놓지 못하는지
2) 두 마음이 다 진짜야. 그래서 더 힘들어
3) 한쪽을 선택해야 하는데 못 하겠어
4) 직접 입력
```

### 실제 적용 예시

**표면적 대화 (❌)**
```
턴1: "어디서 만났어?" → "학교"
턴2: "첫인상이 어땠어?" → "좋았어"
턴3: "그 다음엔?" → "대화했어"
→ 아무런 감정적 깊이 없음
```

**감정 중심 대화 (✅)**
```
턴1: "연인과 헤어진 그 순간, 네 세계가 
      어떻게 무너지는 것처럼 느껴졌어?"
      → "숨을 쉴 수 없을 것 같았어. 
         가슴에 구멍이 난 것 같았어"

턴2: "그 공허함 속에서, 너는 네 자신에게 
      어떤 말을 하고 있었어?"
      → "나는 사랑받을 자격이 없는 사람인가봐. 
         항상 버림받아"

턴3: "그 목소리... '사랑받을 자격이 없다'는 
      그 목소리가 정말 네 목소리일까? 
      아니면 아픔이 만들어낸 목소리일까?"
      → "...생각해본 적 없어. 
         그냥 당연한 줄 알았어"

→ 깊은 자기 이해와 통찰
```

### 교사를 위한 가이드

**이 Agent를 사용할 때**

1. **학생들에게 안전한 공간임을 명확히** - 판단하지 않는 공간
2. **완벽한 답이 없음을 강조** - 모든 감정은 유효함
3. **4번(직접 입력)을 장려** - 깊은 성찰을 위해
4. **힘든 감정이 나와도 괜찮음** - 이것이 바로 치유의 시작

**주의사항**

- 학생이 너무 힘들어하면 전문 상담 연계
- 트라우마가 있는 학생은 주의 깊게 관찰
- 그룹 발표 시 프라이버시 존중
