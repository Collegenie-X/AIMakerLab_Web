# 6차시 AI 학습 도우미 (TM + ESP32 CAM)

## 📚 프로젝트 개요

**Teachable Machine Pose Model**로 학습 자세 및 집중도를 모니터링하는 스마트 학습 도우미

### 시스템 구조도

```mermaid
graph TB
    subgraph "AI 학습 도우미 시스템"
        A[ESP32 CAM] -->|WiFi| B[앱인벤터 앱]
        B -->|포즈 데이터| C[Teachable Machine<br/>Pose Model]
        C -->|자세 분류| D{학습 상태}
        
        D -->|집중| E[타이머 진행]
        D -->|산만| F[알림 전송]
        D -->|휴식| G[휴식 시간 체크]
        
        E --> H[학습 통계 저장]
        F --> I[집중 유도 메시지]
        G --> J[휴식 시간 관리]
        
        H --> K[Google Sheets<br/>학습 분석]
        
        style C fill:#ffe1f5
        style E fill:#ccffcc
        style F fill:#ffffcc
    end
```

## 📊 과정 정보

| 항목 | 내용 |
|------|------|
| **수업 시간** | 6차시 (90분 × 6 = 540분) |
| **대상** | 중학교 1-3학년 |
| **난이도** | ⭐⭐ 보통 |
| **AI 도구** | Teachable Machine Pose Model |

### 포즈 인식 데이터

| 클래스 | 설명 | 데이터 수 | 특징점 |
|--------|------|----------|--------|
| 집중 | 바른 자세로 공부 | 100개 포즈 | 머리/어깨/팔 위치 |

| 부재 | 자리 비움 | 80개 포즈 | 사람 없음 |

- 집중력 방해 요소 찾기
- 바른 학습 자세 연구
- AI 학습 도우미 필요성 토론

### 3차시: 모델 훈련 및 테스트
- TM에서 Pose 모델 학습
- 실시간 포즈 인식 테스트
- 정확도 측정 및 개선
- 모델 내보내기

**정확도 목표:**
| 클래스 | 목표 정확도 | 중요도 |
|--------|------------|--------|
| 집중 | 95% | 매우 높음 |
| 산만 (스마트폰) | 90% | 높음 |
| 산만 (엎드림) | 90% | 높음 |
| 휴식 | 85% | 중간 |
| 부재 | 95% | 높음 |

- ESP32 CAM 설정
- 부저 알림 프로그래밍
- LED 상태 표시
- 알림 메시지 디자인

### 5차시: 앱인벤터 통합
- TM Pose 모델 임포트
- 포모도로 타이머 구현
- 실시간 자세 모니터링
- 학습 통계 기록 (Google Sheets)

**앱 기능:**
| 기능 | 설명 |
