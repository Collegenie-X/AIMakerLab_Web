# 6차시 AI 식물 질병 진단 (PIC + ESP32 CAM)

## 🌿 프로젝트 개요

**Personal Image Classifier**로 식물의 잎 상태를 분석하여 질병을 조기 진단하는 스마트 농업 시스템

### 시스템 구조도

```mermaid
graph TB
    subgraph "AI 식물 질병 진단 시스템"
        A[ESP32 CAM] -->|WiFi| B[앱인벤터 앱]
        B -->|잎 이미지| C[Personal Image<br/>Classifier]
        C -->|상태 분류| D{식물 건강}
        
        D -->|건강| E[정상 관리 안내]
        D -->|질병 초기| F[조기 치료 안내]
        D -->|질병 심각| G[긴급 치료 필요]
        
        E --> H[관리 팁 제공]
        F --> I[치료 방법 안내]
        G --> J[전문가 상담 권장]
        
        B --> K[Google Sheets<br/>성장 기록]
        
        style C fill:#ffe1f5
        style E fill:#ccffcc
        style G fill:#ffcccc
    end
```

## 📖 차시별 상세 내용

### 1차시: 식물 질병 조사
- 흔한 식물 질병 종류 학습
- 질병별 증상 관찰
- 식물 건강의 중요성 인식
- AI 진단 시스템 필요성 토론

**질병 조사 표:**
| 질병명 | 원인 | 증상 | 전파속도 | 치료난이도 |
|--------|------|------|----------|-----------|
| 세균점무늬병 | 세균 | 갈색 반점 | 빠름 | 어려움 |
| 흰가루병 | 곰팡이 | 흰 가루 | 중간 | 보통 |
| 진딧물 | 해충 | 구멍, 즙 흡수 | 빠름 | 쉬움 |
| 질소 결핍 | 영양 | 노란 잎 | 느림 | 쉬움 |

### 2차시: Personal Image Classifier 데이터 수집
- 건강한 식물과 병든 식물 준비
- 각 상태별 60-80장 촬영
- 일정한 조명과 배경에서 촬영
- 다양한 진행 단계 포함

**촬영 가이드:**
```mermaid
graph TD
    A[촬영 가이드] --> B[조명]
    A --> C[배경]
    A --> D[각도]
    A --> E[거리]
    
    B --> B1[자연광 또는 LED]
    B --> B2[그림자 최소화]
    
    C --> C1[흰색 또는 단색]
    C --> C2[잎만 보이게]
    
    D --> D1[정면]
    D --> D2[약간 비스듬히]
    
    E --> E1[10-20cm]
    E --> E2[잎 전체 포함]
    
    style A fill:#e1f5ff
```

### 3차시: PIC 모델 학습 및 검증
- PIC에서 6개 클래스 학습
- 학습 진행 (3-5분)
- 다양한 샘플로 테스트
- 정확도 개선 (추가 데이터)

**정확도 향상 전략:**
| 문제 | 원인 | 해결 방법 |
|------|------|----------|
| 건강/초기질병 혼동 | 미세한 차이 | 초기 증상 데이터 추가 |
| 조명에 따라 달라짐 | 조명 불균일 | 다양한 조명 데이터 |
| 배경 영향 | 배경 복잡 | 흰 배경 통일 |

### 4차시: 진단 시스템 제작
- ESP32 CAM 촬영 부스 제작
- LED 링 라이트 설치
- 토양 습도 센서 연결
- 자동 촬영 시스템 구축

**촬영 부스 구조:**
```mermaid

    A[촬영 부스] --> B[상단: ESP32 CAM]
    A --> C[주변: LED 링 라이트]
    A --> D[하단: 흰색 배경판]
    A --> E[측면: 가이드 라인]

    C --> C1[균일한 조명]
    D --> D1[배경 통일]
    E --> E1[잎 위치 가이드]
    
    style A fill:#e1f5ff
```
