```
배운다  →  만든다  →  수료증  →  ⛔ 끝
```

```
배운다 → 만든다 → 대회 출품 → 전시회 → 상용화 론칭 → 숏츠 광고 → 시장 반응

네이비→오렌지 그라데이션 노드, 굵은 화살표
