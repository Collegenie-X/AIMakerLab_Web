## 1. 블록코딩 AI 비전

> **3시간 모듈형 블록 코딩 AI + 피지컬 컴퓨팅**

### 1.1 과정 소개

**블록코딩 AI 비전**

블록코딩 + AI + 마이크로비트,3시간씩 프로젝트를 완성하는 역공학 기반 메이커 수업

#### 핵심 특징

- 🔹 **3시간 완성 프로젝트**
- 🔹 **피지컬 컴퓨팅 + Teachable Machine**
- 🔹 **AI 학습 및 활용**
- 🔹 **기획-실행-성찰**
---
### 1.2 수강 정보

| 항목 | 내용 |
|------|------|
| 수업 시간 | 3시간 단위 (주제형) |
| 수강 대상 | 초등학생,중학생 |
| 수강 인원 | 최대 20명 (2인 1팀) |
| 수업 방식 | 역공학 + 메이커 교육 |
| 학습 단계 | 기획자→실행자→디버거 |
---
### 1.3 과정 상세 설명

**블록 코딩 AI 수업이란?**

<p><strong>기업 기술을 따라 만들며 배우는 수업입니다.</strong> 구글, 아마존 같은 회사의 실제 제품을 보고, 어떤 기술을 사용했는지 분석합니다. 그리고 우리도 따라서 만들어보면서 원리를 자연스럽게 이해하게 됩니다.</p>

<p><strong>수업은 3시간 동안 5단계로 진행됩니다.</strong> 기업 제품 분석(15분), 기술 원리 배우기(15분), AI 모델 만들기(45분), 시스템 완성하기(60분), 테스트하기(30분) 순서로 진행하여 3시간 안에 작동하는 프로젝트를 완성합니다.</p>

<p><strong>난이도를 선택할 수 있습니다.</strong> 초급은 Teachable Machine과 블록코딩으로 시작하고, 중급에서는 마이크로비트를 추가하며, 고급에서는 여러 센서를 다룹니다. 원하는 만큼 조합하여 6시간, 9시간, 12시간 과정으로 확장할 수 있습니다.</p>
---
### 1.4 학습 목표

**학습 목표 및 기대 효과**

3시간 안에 회사 제품을 분석하고 따라 만들면서 배우기

#### 목표 1: 회사 기술 보고 따라하기

- **카테고리**: 따라 만들기
- **설명**: 실제 제품을 보고 분석해서 따라 만들기
- **핵심 스킬**:
  - 구글, 아마존 같은 회사 제품 분석하기
  - 회사가 쓴 기술 이해하기
  - 내가 만들 수 있는 부분 찾기
  - 중국 방식으로 따라 만들기

#### 목표 2: 분석-배우기-만들기

- **카테고리**: 실습 중심
- **설명**: 기술 분석하고 배운 뒤 직접 만들기
- **핵심 스킬**:
  - 회사 기술 분석하기
  - 기술 원리 배우기
  - AI 모델 만들기
  - 테스트하고 고치기

#### 목표 3: AI + IoT 기술

- **카테고리**: 기술 배우기
- **설명**: 블록 코딩으로 AI와 하드웨어 연결하기
- **핵심 스킬**:
  - Teachable Machine으로 AI 만들기
  - DWAI 블록 코딩하기
  - 마이크로비트 쓰기 (중급)
  - 센서 제어하기 (고급)

#### 기대 성과

- ✅ 3시간 안에 프로젝트 1개 완성
- ✅ 실제 회사 기술 분석하고 이해하기
- ✅ 따라 만들며 기술 배우기
- ✅ 작동하는 시스템 완성
- ✅ 포트폴리오 작품 만들기

### 1.8 상세 커리큘럼

**3시간 모듈형 프로젝트 선택**

난이도별 다양한 주제 중 원하는 것을 선택하세요 (조합 가능)

#### 📚 프로젝트 1: 초급 A: 마스크 착용 인식 게임 | 난이도: 초급

공항/병원의 실제 방역 시스템 기술을 벤치마킹하여 마스크 인식 AI 게임을 만듭니다. 기업이 사용하는 기술을 분석하고, 우리가 따라 만들 수 있는 부분까지 접근합니다.

##### ⏱️ 수업 구성 (3시간)

*벤치마킹 → 기획 → 실행 → 디버깅*

**1. 벤치마킹 & 기술 이해 (30분)** (0.5시간)

  실제 기업의 방역 기술을 분석하고 따라 만듭니다

  - 벤치마킹: 공항/병원 마스크 감지 시스템 (실제 기업 기술)
  - 기술 분석: 어떤 AI 기술을 사용했나? 어떻게 작동하나?
  - 기술 배경 이해: Teachable Machine 이미지 인식 원리
  - 따라하기: 마스크 착용 여부 판정 게임 만들기

**2. AI 모델 제작 (45분)** (0.75시간)

  Teachable Machine으로 마스크 인식 AI를 학습시킵니다

  - 데이터 수집 전략: 다양한 각도와 조명
  - 클래스 1: 마스크 정상 착용 (50장)
  - 클래스 2: 마스크 없음 (50장)
  - 클래스 3: 코 노출 (50장)
  - 모델 테스트 및 개선

**3. 게임 구현 (60분)** (1시간)

  DWAI 블록 코딩으로 게임을 만듭니다

  - TM 모델 DWAI 연동
  - 3가지 상태별 메시지 및 이미지
  - 점수 시스템: 정상 착용 시 +10점
  - 효과음 및 애니메이션
  - 게임 UI 디자인

**4. 디버깅 & 성찰 (25분)** (0.42시간)

  테스트하고 개선하며 성찰합니다

  - 기능 테스트: 3가지 상태 정확히 인식?
  - 오류 수정: 잘못 인식되는 경우 개선
  - 사용성 개선: 더 재미있게
  - 성찰: 배운 점, 아쉬운 점, 다음 개선 방향

##### ⏱️ 3시간 (3시간)

*메이커 교육 방식 - TM 기반 보안 시스템*

**1. 1단계: 벤치마킹 + 기술 배경 이해** (30분)

  - 시중 스마트홈 보안 제품 분석 (링 초인종, 네스트 캠 등)
  - 작동 원리 역공부 (센서, 카메라, 알림)
  - 사용자 정의: 우리 집/학교를 지키려는 가족/선생님
  - 사용 시나리오 작성

**2. 2단계: 기획 + 실행** (2시간)

  문제를 정의하고 TM과 App Inventor를 활용하여 실제 보안 시스템을 제작합니다.

  - 진짜 문제: 집에 없을 때 침입자를 어떻게 감지할까?
  - ESP32-CAM + 모션센서 연결
  - Teachable Machine으로 얼굴 인식 모델 학습
  - App Inventor로 간단한 알림 앱 제작
  - WiFi 연결 및 시스템 통합

**3. 3단계: 디버거(성찰)** (30분)

  완성된 시스템을 테스트하고 개선점을 찾아 발표합니다.

  - 시스템 테스트: 가족 vs 낯선 사람 인식률
  - 문제점 발견 및 개선 방안 토론
  - 사용자 피드백 반영
  - 프로젝트 발표 및 시연

##### ⏱️ 6시간 (6시간)

*메이커 교육 방식 - TM + App Inventor + STT 통합*

**1. 1단계: 벤치마킹 + 기술 배경 이해** (1시간)

  기업의 스마트홈 보안 기술을 분석하고 따라 만들 부분을 선정합니다.

  - 벤치마킹: Google Nest Cam, Amazon Ring (실제 기업 제품)
  - 기술 분석: 어떤 센서와 AI를 사용? 통신 방식은?
  - 기술 배경 이해: 얼굴 인식, 음성 제어, 원격 모니터링 원리
  - 따라할 부분 선정: ESP32-CAM으로 구현 가능한 범위

**2. 2단계: 기획(진짜 문제 정의)** (1시간)

  사용자의 진짜 문제를 정의하고 해결 방법을 설계합니다.

  - 진짜 문제: 집에 있는 반려동물/노인의 안전을 실시간으로 확인하고 싶다
  - 해결 방법: 얼굴 인식 + 음성 명령 + 실시간 영상
  - 시스템 구조 설계: ESP32-CAM ↔ WiFi ↔ App Inventor
  - 기능 우선순위 정하기

**3. 3단계: 실행자 - 하드웨어 제작** (1.5시간)

  TM으로 AI 모델을 학습하고 ESP32-CAM 하드웨어를 완성합니다.

  - ESP32-CAM + 모션센서 + 스피커 연결
  - Teachable Machine으로 얼굴/동물 인식 모델 학습
  - 모델을 ESP32에 통합 (TFLite 변환)
  - WiFi 웹서버 구축 및 영상 스트리밍

**4. 3단계: 실행자 - 앱 개발** (1.5시간)

  App Inventor로 사용자 친화적인 모니터링 앱을 제작합니다.

  - App Inventor로 모니터링 앱 UI 설계
  - 실시간 영상 표시 기능
  - 음성 명령(STT): '경보 켜줘', '영상 보여줘'
  - 푸시 알림 기능 구현
  - ESP32와 앱 연동 테스트

### 5.3 과정 상세 설명

**바이브 코딩이란?**

<p><strong>바이브 코딩은 거꾸로 배우기와 직접 만들기를 합친 학습 방법입니다.</strong> 일반 공부는 이론을 먼저 배우고 실습하지만, 바이브 코딩은 완성품을 먼저 보고 거꾸로 만들어가며 배웁니다. 이 과정에서 문제를 여러 각도에서 보는 연습을 하게 됩니다.</p>

<p><strong>1단계는 문제 찾고 만들기입니다 (3-6시간).</strong> 좋은 사례를 찾아보고, 사용자 입장에서 생각하며, 진짜 필요한 게 뭔지 찾습니다. ChatGPT에게 명령하는 것이 아니라 대화하며 협업하여 동화책, 영어 튜터, 감정 게임 같은 작품을 만듭니다.</p>

<p><strong>2단계는 자동으로 만들기입니다 (16시간).</strong> 1단계에서 손으로 만든 것을 Cursor와 V0를 사용해서 자동화합니다. 버튼 한 번에 컨텐츠가 만들어지도록 처음부터 끝까지 전체 시스템을 만들어봅니다.</p>

<p><strong>핵심은 직접 만들면서 배우는 것입니다.</strong> 이론 수업 없이 실패하고 고치고 다시 시도하는 과정에서 진짜 실력이 쌓입니다. ChatGPT를 도구가 아니라 친구처럼 활용하는 방법을 배웁니다.</p>

*수동 제작으로 AI 활용법 체득*

  - 베스트셀러 동화책 3-5개 읽기
  - 무엇이 좋은 동화책인가? 다각적으로 분석

**2. 사용자 관점에서 진짜 문제 발견** ()

  - 페르소나 정의: 누구를 위한 동화책인가? (나이, 관심사, 고민)
  - 그들이 가진 진짜 문제는 무엇인가? (표면적 vs 본질적)

  - 동화책으로 어떤 가치를 줄 것인가? (솔루션)

> **AI 융합 과정**

### 6.1 과정 소개

**AI 심화 제작 코딩**

IoT 제작과 AI 서비스 개발을 통한 실전 프로젝트

#### 핵심 특징

- 🔹 **기획부터 실행**
- 🔹 **IoT 제작**
- 🔹 **AI 서비스**
- 🔹 **포트폴리오**

### 6.2 수강 정보

| 항목 | 내용 |
|------|------|
| 수업 기간 | 3개월 (12주) |
| 수강 인원 | 4-6명 소규모 수업 |
| 수업 방식 | 프로젝트 기반 실습 |
| 총 학습 시간 | 48시간 |

### 6.3 과정 상세 설명

**AI 심화 제작 수업이란?**

<p><strong>AI 심화 제작 수업은 IoT 제품과 AI 서비스를 실제로 만들어보는 수업입니다.</strong> IoT 하드웨어를 직접 제작하고, AI 기술을 활용한 웹 서비스를 개발하면서 실전 프로젝트 경험을 쌓습니다. 3개월 동안 기획부터 실행까지 전체 과정을 경험합니다.</p>

<p><strong>기획부터 실행까지 전 과정을 배웁니다.</strong> 하드웨어와 AI를 합쳐서 실제로 작동하는 제품을 만들고, 이 과정에서 제품 개발 능력을 키웁니다. 단순히 코딩만 배우는 것이 아니라 문제를 정의하고 해결하는 전체 프로세스를 익힙니다.</p>

<p><strong>최신 AI 도구를 활용하여 빠르게 개발합니다.</strong> ChatGPT, Cursor, V0 같은 최신 AI 도구를 사용해서 빠르게 프로토타입을 만들고, 계속 고치고 개선하면서 완성도 높은 결과물을 만드는 방법을 배웁니다.</p>

### 6.4 학습 목표

**학습 목표**

이 과정을 통해 얻을 수 있는 역량

#### 목표 1: 문제 발견 및 정의

- **카테고리**: 기획 능력
- **설명**: 실생활의 문제를 발견하고 AI로 해결할 수 있는 방법을 기획합니다
- **핵심 스킬**:
  - 문제 분석 및 정의
  - 요구사항 도출
  - 기획서 작성
  - 프로젝트 설계

#### 목표 2: AI 도구 활용 개발

- **카테고리**: 실행 능력
- **설명**: ChatGPT, Claude 등 AI 도구를 활용하여 빠르게 프로토타입을 제작합니다
- **핵심 스킬**:
  - AI 도구 활용
  - 프롬프트 엔지니어링
  - 빠른 프로토타이핑
  - 반복 개선

#### 목표 3: 하드웨어 + AI 융합

- **카테고리**: IoT 제작
- **설명**: 라즈베리파이, ESP32 등을 활용하여 AI와 결합한 IoT 제품을 만듭니다
- **핵심 스킬**:
  - 센서 제어
  - 카메라 활용
  - AI 비전 연동
  - 실시간 데이터 처리

#### 목표 4: AI 웹 서비스 개발

- **카테고리**: 웹 서비스
- **설명**: 바이브 코딩으로 AI 기능이 포함된 웹 서비스를 개발합니다
- **핵심 스킬**:
  - 프론트엔드 개발
  - API 연동
  - AI 모델 통합
  - 서비스 배포

#### 기대 성과

- ✅ 실전 프로젝트로 포트폴리오 완성
- ✅ 문제 정의부터 완성까지 전 과정 경험
- ✅ AI 도구 활용 능력 습득
- ✅ 하드웨어와 소프트웨어 융합 경험
